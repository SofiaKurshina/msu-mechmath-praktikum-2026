### Описание реализованной задачи

Программа решает **Задачу №13: Метод Гаусса нахождения обратной матрицы с выбором главного элемента по строке**. 

Алгоритм основан на методе Гаусса для решения матричного уравнения $AX = E$. Для повышения численной устойчивости на каждом шаге прямого хода в текущей строке ищется максимальный по модулю элемент. Вместо перестановки строк, алгоритм меняет местами столбцы матрицы $A$, а в конце работы с помощью массива перестановок восстанавливает правильный порядок строк в итоговой обратной матрице $X$. 

После нахождения обратной матрицы программа вычисляет и выводит нормы невязки $\|AA^{-1} - E\|$ и $\|A^{-1}A - E\|$, а также время, затраченное на вычисления. Для соблюдения требования по памяти ($2n^2 + O(n)$) перед вычислением невязки исходная матрица $A$ инициализируется заново.

### Сборка и запуск программы

**1. Сборка (Компиляция)**
Для компиляции программы используется компилятор GCC. В терминале, находясь в папке с исходными файлами (`task.c`, `solve.c`, `array_io.c`), выполните следующую команду:

```bash
make
```

**2. Запуск**
Программа принимает аргументы командной строки в следующем формате:
```bash
./a.out <n> <m> <k> [filename]
```

**Аргументы:**
* `n` — размерность квадратной матрицы ($n \times n$).
* `m` — максимальное количество строк и столбцов матрицы, которое будет выведено на экран.
* `k` — номер формулы инициализации матрицы (от 1 до 4). Если матрица читается из файла, аргумент должен быть равен `0`.
* `filename` — имя текстового файла с матрицей (указывается **только** если `k = 0`).

**Примеры запуска:**
* Инициализация матрицы 10x10 по формуле №1 с выводом первых 5 строк и столбцов:
  ```bash
  ./a.out 10 5 1
  ```
* Чтение матрицы 4x4 из файла `matrix.txt` с полным выводом на экран:
  ```bash
  ./a.out 4 4 0 matrix.txt
  ```

**Формат файла (если k=0):**
Текстовый файл должен содержать элементы матрицы, разделенные пробелами или переносами строк, в количестве ровно $n \times n$ штук.
